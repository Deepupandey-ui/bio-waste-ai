# ⚙️ Installation & Setup

## 1️⃣ Clone Repository

```bash
git clone https://github.com/your-username/bio-waste-ai.git
cd bio-waste-ai
```

---

## 2️⃣ Build Backend

```bash
cd backend/backend
mvn clean package -DskipTests
```

---

## 3️⃣ Run Docker Containers

Go back to root folder:

```bash
cd ../../
```

Run Docker:

```bash
docker compose up --build
```

# 🔄 Application Workflow

```text
User Uploads Waste Image
           ↓
Frontend Sends Request
           ↓
Spring Boot Backend Processes Image
           ↓
AI/Logic Classifies Waste
           ↓
System Generates:
- Waste Type
- Waste Percentage
- Product Suggestions
- Environmental Impact
- Nearby Buyers
           ↓
Results Displayed on Dashboard
```
